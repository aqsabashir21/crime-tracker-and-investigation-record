# Crime Record and Investigation Tracker

## About Project
This project helps maintain detailed records of criminal cases.  
It supports efficient investigation by organizing evidence, suspects, and case progress in one system.

## Features
- Add and update crime records
- Track suspects and evidence
- Monitor investigation progress
- Generate summary reports
